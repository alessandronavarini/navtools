# NavTools

Piccoli strumenti web per semplificare l'operativita quotidiana in finanza.

Il progetto è pensato per GitHub Pages e usa HTML, CSS e JavaScript puro: nessun backend, nessun database e nessun framework.

## Strumenti

- Disinvestimento Fondi: calcolo del lordo da netto e del netto da lordo con fiscalità e commissioni SGR.
- Importo Mutuo Erogabile: stima il massimo importo finanziabile partendo dal reddito netto mensile, dagli impegni già in corso, dal tasso fisso e dalla durata desiderata.

## Roadmap

- Calcolatore PAC/PIC
- Simulatore rendimento
- Duration e obbligazioni
- Cedole, ETF, fiscalità e pianificazione finanziaria
